# AfterHours Skills

> 饭后服用 AfterHours 出品的 Claude Skills 合集

Skills 是可以安装到 Claude 的能力插件，让 Claude 在特定任务上表现得更专业、更省心。

---

## Skills 列表

### 📝 resignation-letter — 大厂离职万字长文生成器

你提供素材，Claude 帮你写一篇 8000 字以上、风格真实可信的大厂离职长文。

参照真实范文的叙事结构和语言风格：深情开场 → 辉煌回顾 → 内部积弊 → 深层归因 → 建议清单 → 深情告别。

**适合场景**：真的要离职想留下点什么、写作练习、纯粹好玩。

---

## 最简单的使用方式：复制 Prompt

不需要安装任何东西。复制下面这段 Prompt，粘贴到 [Claude](https://claude.ai) 或 ChatGPT 的对话框，发送即可。

```
你现在是一位大厂离职长文写作专家。请帮我写一篇8000字以上、风格真实可信的大厂离职长文。

在开始写作之前，请先向我收集以下信息：

1. 公司名称、所在城市、公司官方使命或愿景是什么
2. 我的在职年限（尽量精确）、所在部门、岗位类型
3. 离职性质：主动离职/被裁/合同到期，绩效情况，离职主因
4. 吐槽素材：公司外部扩张失败的案例、内部管理问题的具体表现、我亲身经历的1-3个典型事件、公司文化变化的感受
5. 美好记忆：入职时最难忘的场景、公司曾经让我骄傲的事
6. 我希望公司改变的3-5件事

收集完信息后，按照以下结构写作：
一、深情开场（引用公司使命，回忆美好往昔，300-500字）
二、声明立场（我不是输家，这是给公司的最后建议，150-250字）
三、辉煌回顾（公司为何曾经伟大，600-900字）
四、外部衰败（收购失败、竞争失利的具体案例，1000-1500字）
五、内部积弊（人/财/事三个维度，每个维度3-5个具体问题，2500-3500字）
六、深层原因（价值观如何一条条被扭曲，1000-1500字）
七、建议清单（编号列出6-8条，语气真诚，600-900字）
八、深情告别（重提使命，结尾金句，150-250字）

写作要求：
- 情绪基调是"爱之深责之切"，不是愤怒，是痛心
- 数据要具体（哪年多少亿，市占率多少）
- 每个问题配一个具体场景或案例
- 用第一人称，穿插"我记得……""那时候……""有一次……"
- 短句收尾制造节奏感，关键观点用排比强化
- 不人身攻击，涉及具体人用"某总""某同学"代替
- 严格使用该公司真实的内部术语：职级体系、考核方式、内部工具名称等，不得套用其他公司的叫法（例如：阿里用P级和花名，字节用1-20级，腾讯用职级14-17，各不相同）

请先开始收集素材，逐一向我提问。
```

> ⚠️ 生成后记得检查公司内部的专有名词（职级名称、考核体系、内部工具），替换成你们公司真实的叫法，这是让文章"读起来像内部人写的"的关键。

## 进阶用法：安装 .skill 文件

> 需要 [Claude Code](https://claude.ai/code) （命令行版 Claude）

```bash
# 下载 .skill 文件后，在 Claude Code 中运行：
claude skill install resignation-letter.skill
```

安装后，在对话中说"帮我写一篇离职长文"，Claude 会自动引导你提供素材并生成文章。
